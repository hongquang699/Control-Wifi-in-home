ABOUT NETWORK MANAGER

Giới Thiệu Hệ Thống Quản Lý Mạng

Tổng quan về mục tiêu, kiến trúc phân tầng 3 lớp và các công nghệ cốt lõi của Network Manager.

1 Hệ thống Network Manager là gì?

Network Manager là bộ giải pháp phần mềm quản trị và giám sát mạng nội bộ (LAN/WLAN) chuyên nghiệp. Khác với các công cụ quét IP thông thường, hệ thống tích hợp khả năng phân tích đa tầng (Multi-tier Topology), bóc tách rõ ràng giữa Modem Tổng ISP và Router Phụ, xác định phương thức liên kết Wi-Fi/LAN và cung cấp khả năng chặn thiết bị trực tiếp tại Router phần cứng.

Tính Năng Hệ Thống Quản Lý Mạng

Đầy đủ 7 module chức năng phục vụ toàn diện công tác quản trị và an ninh mạng nội bộ.

💻

1. Quản lý thiết bị (Device Management)

Nhận diện IP, MAC, nhà sản xuất OUI, phân loại 6 nhóm thiết bị và cho phép gán tên gợi nhớ Alias.

📡

2. Giám sát mạng (Network Monitoring)

Tự động quét định kỳ dải mạng theo chu kỳ cấu hình, phát hiện tức thì biến động kết nối.

⚡

3. Kiểm tra trạng thái (Status Checking)

Đo độ trễ phản hồi ping tính bằng ms, hiển thị trạng thái Online, Offline, Blocked trực quan.

🌐

4. Quản lý IP (Subnet & IP Allocation)

Phân tách dải Wi-Fi Tổng 192.168.1.x và Router Phụ 192.168.110.x, phát hiện đổi IP bất thường.

📈

5. Theo dõi băng thông (Traffic Tracking)

Biểu đồ sóng động hiển thị tốc độ Upload / Download theo thời gian thực.

🔔

6. Cảnh báo an ninh (Real-time Alerts)

Phát thông báo khi có thiết bị mới kết nối, ngắt kết nối hoặc vi phạm quy định mạng.

📜

7. Nhật ký hoạt động (Audit Logs)

Lưu vết toàn bộ sự kiện mạng vào cơ sở dữ liệu SQLite cục bộ, hỗ trợ truy xuất và kiểm toán an ninh.

Tài Liệu Kỹ Thuật & Hướng Dẫn

Cẩm nang hướng dẫn cài đặt, sử dụng, đặc tả API RESTful, 5 câu hỏi thường gặp và xử lý sự cố.

1. Hướng dẫn cài đặt hệ thống

Network Manager hỗ trợ cài đặt nhanh chóng trên cả 3 nền tảng chính:

# Windows (Khuyên dùng)
Tải tệp ZIP, giải nén và nhấp đúp run.bat hoặc run_admin.bat để chạy ngay không cần cài đặt Python.
# Linux (Ubuntu / Debian)
tar -xzf NetworkManager-v1.0.0-linux-x64.tar.gz
sudo ./network_manager

2. Hướng dẫn sử dụng

  1. Quét mạng tự động: Khởi chạy app để hệ thống tự nhận diện Card mạng và quét toàn bộ dải IP.
  2. Gán tên gợi nhớ (Alias): Nhấp "Chi tiết" ở dòng thiết bị tương ứng để nhập tên gợi nhớ như "Laptop làm việc".
  3. Sơ đồ phân cấp: Xem cây topo Internet ➔ Modem Tổng ➔ Router Phụ ➔ Thiết bị đầu cuối.
  4. Chặn truy cập: Nhấp nút "Chặn" để đưa MAC vào danh sách blacklist của Router.

3. Đặc tả API RESTful

GET /api/v1/health
Kiểm tra tình trạng sống của API server.
GET /api/v1/stats
Lấy các chỉ số tổng quan mạng theo thời gian thực (Online, Offline, Traffic, CPU/RAM).
GET /api/v1/devices
Lấy danh sách tất cả các thiết bị kết nối.
POST /api/v1/devices/{mac}/block
Gửi lệnh chặn thiết bị tới Router & Windows Firewall.

4. 5 Câu Hỏi Thường Gặp (5 FAQs)

1. Ứng dụng có cần quyền Administrator không?

Không bắt buộc. Quyền Admin chỉ cần thiết khi bạn muốn kích hoạt tính năng tường lửa hai chiều Windows Firewall hoặc gửi gói tin raw socket Nmap ở tốc độ cao nhất.

2. Không cài đặt phần mềm Nmap có chạy được không?

Hoàn toàn được. Hệ thống tích hợp sẵn động cơ kép: Khi không tìm thấy Nmap, phần mềm tự chuyển sang bộ quét Native ARP + Ping ICMP đa luồng với độ chính xác cao.

3. Chế độ Mock Router Mode dùng để làm gì?

Mock Mode là môi trường sandbox giả lập 100% an toàn, cho phép bạn thử nghiệm tính năng Chặn/Bỏ chặn và demo ứng dụng mà không cần cấu hình mật khẩu router thật.

4. Network Manager quản lý mạng có nhiều Router phụ như thế nào?

Hệ thống có thuật toán Topology Analyzer tự động bóc tách các dải subnet riêng (ví dụ 192.168.1.x của Modem Tổng và 192.168.110.x của Router Phụ) và vẽ sơ đồ phân cấp trực quan.

5. Cơ chế chặn thiết bị hoạt động ở mức độ nào?

Cơ chế bảo vệ 2 lớp: Lớp 1 gửi lệnh phần cứng (MAC Filtering/ACL/iptables) trực tiếp tới Router; Lớp 2 tạo quy tắc Inbound & Outbound trên Windows Host Firewall của máy quản trị.

5. Xử lý lỗi (Troubleshooting)

  • Quét không ra thiết bị: Đảm bảo mạng của bạn đang đặt ở chế độ Private Network trên Windows.
  • Lỗi kết nối Router: Kiểm tra lại địa chỉ Gateway IP và mật khẩu đăng nhập trong phần Cài đặt.
